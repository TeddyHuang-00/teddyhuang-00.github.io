## 1. 改稿总纲

**核心判断（一段话）**：AI 进入科研不可避免、也不该抗拒——草稿最原创的观察是对的，科研是一种"只见成果、不见来路"的创意工作，因此人与 AI 交互产生的研究轨迹是此前从未有过、也无法从成品反推的稀缺数据，值得收集，作者支持收集；但收集的方式已经出问题：近期的两起事件（Navier–Stokes 证明、Anthropic 的酶发现）都以"新闻标题"的方式宣告成果，把优先权、贡献归属和数据来源上的争议留给了科研共同体，而这套共同体赖以运转的引用与致谢机制，恰恰建立在"来源可见、可追溯"这个前提上。人与人之间的信任还能撑，人与 AI 之间这层信任从未被建立。因此本文主张一条底线式的、可执行的方案：**双向退出**——对不遵守科研规范的 AI 公司与研究者，共同体主动停止供数据、停止默认信任其成果；否则崩塌的不是某一篇论文，而是整个科研系统的信任机制。

**分析层次框架（开头就要给出，全文按这三层递进）**：

1. **事实层**：AI 已经在做科研，也已经在收数据（谁在收、什么价格、收到了什么——§3、§4）。
2. **机制层**：科研靠引用与致谢构成的可追溯性运转，这套机制脆弱但可修（§5、§6）。
3. **制度层**：既然逐篇核查追不上生成速度，就退回"让不守规范的一方支付成本"（§7）。

**文章要回答的问题**：当 AI 成为科研的协作者，什么样的收集方式和发表方式是可接受的？**明确不回答的问题**（写进首节，与前作一致）：不预测 AI 什么时候能独立做出重大成果；不评估具体公司的模型能力；不做技术路线之争。

**立场不可动**（改稿任何阶段都不许弱化或反转）：① AI 做科研不可避免、不应抗拒；② 支持收集科研轨迹数据；③ 双向退出机制；④ 以人为本的科研交流。

### 2.1 `## 写在前面`（250–400 字）

- **功能**：给出三层框架（事实 / 机制 / 制度）与核心判断；交代"本文回答什么、不回答什么"。前作两篇的首节都是这个位置（SB §2.1）。
- **核心问题**：AI 已经不是第一次进入创意领域，这一次进入科研，为什么值得单独写一篇？
- **末段回应方向**：一句话把立场钉住——AI 做科研不可避免，收集科研轨迹有必要，但"怎么收、怎么宣告"决定后果。
- **过渡钩子**：先解释为什么科研的"过程"值得收集（"过程为什么比成品贵，得从科研这份工作本身说起"）。

### 2.2 `## 神龙见首不见尾：一份从未被记录过的过程`（1000–1200 字）

- **功能**：先把草稿最原创的观察立成事实前提；用创意领域为参照，说明科研与它们的同与不同；再用可核实的规模证据（专家数据市场）与 Tao 的论断补上"稀缺且珍贵"。
- **核心问题**：为什么科研的过程数据既没有被记录过，也不可能从成品反推出来？
- **展开顺序**：① 创意领域的前例（抵制→授权与诉讼→专业工作流内的结合，FD P1-5，注意降级措辞）；② 科研与前几类领域的差距（重视积累与传播、成品密集、但轨迹不可还原；"你只看得见结果，看不见来时路的岔路与断头路"）；③ 同属创意工作的原因（需要"未曾见过的组合"，而组合过程不进成品）；④ 稀缺性的可核实证据（专家数据市场的规模，gross 口径；Tao："it is now the identification of a promising problem which is the scarce and precious resource."）。
- **末段回应方向**：正因为不可还原，这份数据珍贵——所以作者支持收集（立场句落在这里）。
- **过渡钩子**：稀缺的、珍贵的、从公共领域拿不到的数据，会没人来收吗？→ §3。

### 2.3 `## 已经开始的收集：席位、价格与可审计的产物`（1100–1300 字）

- **功能**：把草稿"迟早在某个时间点大规模展开收集"的预判，换成已经发生的可核实动作；再用 coding agent 的价格战先例支撑"一年半载内集体推进"的推演；同时给出"AI 与科学合作"的正例，先说明问题不在 AI 本身。
- **核心问题**：现在是谁、用什么方式在换研究者的使用轨迹？这条打法在别的领域跑过一遍的结果是什么？
- **展开顺序**：① 正例先行（AlphaFold2 与诺奖、GNoME、AI co-scientist、Claude 推进黎曼 ζ 下界，FD P2-a）——AI 与人的合作已经产出被共同体承认的结果；② 收集动作（**草稿所说的"Anthropic 的 research plan"就是这一项**：面向认证研究机构的 10,000 个席位、标准席位免费 / 高级席位每月 15 美元、一年期，AI for Science 额度上限 $50,000；Claude Science "produces auditable artifacts"；FD P1-3 候选 A、B）；③ 价格先例（Grok Code Fast 1 限时免费与 API 定价、Gemini CLI 免费额度；FD P1-4，Grok Build 的免费层级无官方来源，不要写）。
- **末段回应方向**：收集本身不是问题，作者支持收集；问题是"以什么方式取得成果"——两起争议就是方式出问题的样本。
- **过渡钩子**：把"新闻标题式成果宣告"的两种典型摆出来 → §4。

### 2.4 `## 两起争议：约一万个 agent 与一次"自主发现"`（1300–1600 字）

- **功能**：用两起事件说明科研成果宣告与科研共同体要求之间的冲突；本节放**关键事实对照表**（视觉提案 3）与两处英文直引（Tao、25 位菲尔兹奖得主声明）。
- **核心问题**：当 AI 宣称做出成果时，科研共同体真正质疑的是什么？
- **展开顺序**：① Navier–Stokes：官方口径（约一万个并发 agent、Lean 形式化、不申领千禧年奖）、承认对方优先权并致贺、争议点（优先权与私下交涉、Córdoba–Martínez-Zoroa 被边缘化）、"是否解错了问题"的后续（Silvestre 原话 + arXiv:2609.20803）、Tao 的判断（稀缺的是"发现好问题"这件事）；② Anthropic 酶发现：官方口径（仅高层级方向指导、湿实验由人类完成、约 950 个 agent / 21 小时 / 2.1 亿 token）、功能仍未知且未投稿、质疑（Mestre 的时间差与"数据是否用于训练"、Kranzusch 与 Blake 的降级评价）；③ 两案的共同结构：质疑都在公告之后提出、都具名、都指向"来源无法追溯"。
- **末段回应方向**：这两件事暴露的不是某家公司的道德，而是"成果宣告"与"可追溯的来源"之间缺了一环。
- **过渡钩子**：要看清缺的是哪一环，先看科研平时靠什么运转 → §5。

### 2.5 `## 引用、致谢与一套脆弱的机制`（1100–1400 字）

- **功能**：讲清这套机制（Merton 的 CUDOS 与优先权结构、作为反规范的 secrecy）、它的脆弱性（草稿 L21 的推理改写为学术表述）、以及它为什么没有崩（ICMJE 的 AI 条款、伪造引用的处理、可复现性危机后的制度性改革）。
- **核心问题**：科研靠什么让"公开来源"成为理性选择？什么条件下这套机制会崩？
- **展开顺序**：① 机制描述：引用与致谢不是礼仪，是让后来者能接着走、能溯源的公共品（Merton 的 communism / CUDOS）；② 脆弱性：优先权之争不是人性问题，是"原创性"这个规范结构性地产生的（Merton 1957）；secrecy 是与 communism 相对的反规范；③ 历史先例：Photo 51（无署名使用他人数据确有先例）；④ 制度托底：ICMJE"AI 不得署名、必须披露、不披露可构成不当行为"、PubMed 伪造引用比例、可复现性危机后的预注册与数据共享。
- **末段回应方向**：机制脆弱，但历史上它靠制度修补而不是靠人性——这给 §7 的退出机制提供了可行性依据。
- **过渡钩子**：以上全部是人与人之间；AI 进来以后，每一环都有一个对不上的地方 → §6。

### 2.6 `## 当协作者不是人`（1200–1500 字）

- **功能**：拆出人机信任缺口的三个具体来源，并把"未来无人审视时怎么办"明确标记为思想实验；同时把草稿"AI 从代步工具变协作者"的观察接进来。
- **核心问题**：如果成果不是来自空白，而是来自一个读过所有人论文、又拿着对话数据的系统，我们凭什么相信"灵光一闪"？
- **展开顺序**：① 训练语料的封闭性：模型读过所有人的论文，包括没发表的草稿吗（用 OpenAI 自认"无法排除去标识化数据改进模型"这句已核实原话，不要写档案没有来源的"越狱能力"断言）；② 追责链断裂：成果不再逐篇被媒体审视、证据不足时无法追责（思想实验，标为第一人称设想，不加脚注）；③ 协作者化与神格化：从"代步工具"到"协作者"，超出个人掌控范围——所以需要制度而不是自觉。
- **末段回应方向**：这层信任从未被建立，怀疑像一颗带毒的种子，掐晚了的代价是整个科研体系。
- **过渡钩子**：制度长什么样？本文的答案只有一句：双向退出 → §7。

### 2.7 `## 双向退出`（1200–1500 字）

- **功能**：给出主张（对不守规范的 AI 公司与研究者双向退出）+ 现有制度依据（ICMJE 三条原文、伪造引用的处理、可复现性改革的先例）+ 执行层（自组织与行业监管乃至公共系统），并明确底线（AI 不该单独署名）。放站内链接到前作。
- **核心问题**：在逐篇核查追不上生成速度的情况下，什么机制能让"公开来源"继续划算？
- **展开顺序**：① 两个方向各一段（对 AI 公司：不提供数据、不默认信任其成果；对研究者：督促借助 AI 灌水 / 伪造 / 隐性剽窃者退出）；② 为什么可行：已有条款（ICMJE）与已发生的处罚先例（伪造引用、撤稿）；③ 执行主体：自发组织 + 行业监管 / 公共系统，两作互链（`[“AGI 前夜”](../eve-of-AGI)`）。
- **末段回应方向**：退出机制不是惩罚，而是让不守规范的一方支付成本，从而让"公开来源"继续划算。
- **过渡钩子**：回到开头——数据注定要被收集，决定后果的不是谁先收满，而是收的时候有没有把信任一起收走 → §8。

### 2.8 `## 结语`（350–500 字）

- **功能**：回收开头三层框架与"神龙见首不见尾"意象，用场景或开放问题收束（示例：设想十年后一篇论文的致谢栏里多出一行"本研究的部分过程不可追溯"，再问一句"那时我们还相不相信那四个字：AI 发现"）。
- **禁止**："综上所述"、"总而言之"、任何新信息（前作结语之后不补新料，SB §2.4）。
- **末段回应力**：用短句收尾或反问，与前两作一致。

**关于第三级标题**：本方案不用 `###`。理由：`###` 在本站是"同一节内并列的子政策 / 子未来"（eve 的 6 组政策、"两种未来"），本稿没有这种并列结构，强行加会把递进写成并列。若写作者的稿子确实需要（例如 §4 想让 NS 与酶两案各起一个 `###`），按 §9 的开放问题处理，不要自己加。

### 6.3 不加脚注、也不该加脚注的句子

- **作者分析 / 判断句**："他们想要的并不是推进研究的进步，而是一个足够大的新闻标题"——这是推论，不是事实断言；写的时候紧跟一条已核实事实（OpenAI 自认因"传闻"启动、Buckmaster 关于私下交涉的声明），让判断有落脚点，但不挂脚注。
- **未来设想 / 思想实验**："当 AI 的科研成果不再有那么多媒体关注、不再能找到证据指向明确的借鉴来源时……"——第一人称设问，标为设想，不加脚注。
- **修辞与隐喻**："神龙见首不见尾"、"带毒的种子"、"代步工具 → 协作者"——作者语言风格的一部分，不加。
- **价值主张**：支持收集科研轨迹、双向退出、以人为本——立场句，不加。
- **自制分析框架**：§5 的 2×2 协调表（见 §7 备选 4）——作者自制的推理工具，不加。
- **一条硬规则**：凡出现具体数字、日期、"某某说"、机构政策条款的句子，必须有脚注；凡属于作者自己的推理、预测、价值判断，一律不加。

### 7.1 提案 A（Typst）："神龙见首不见尾"轨迹图 → §2

- **画什么**：单面板。左下角一个小实心圆标"问题"；一条**实线**从左下走到右上，抵达一个实心方块标"已发表成果"（实线中段有 1–2 个转折点）；实线周围散布 6–8 条**灰色虚线**：3–4 条半途断掉（断头路）、2–3 条绕远后回到主干（岔路）、1 条通向一个孤立小点（未发表的负结果）；图例标明实线 = 被记录的部分，虚线 = 不可见的部分。
- **论证功能**：把"成品只记录终点"变成可数的事实——读者一眼看出被隐去的路径数量级，从而接受"过程无法从成品反推"这个前提（本稿的地基论证）。
- **实现**：`src/assets/images/ai-for-anything-and-everything/traj.typ`；`#import "../config.typ": *` + `#import "../dependencies.typ": cetz`；cetz `line` / `bezier` + `stroke: (dash: (2pt, 5pt), paint: palette.subtext0)`（虚线写法照 eve 的 `marginal.typ`）；实线用 `palette.red`，成果方块用 `palette.foreground`，空白负结果点用 `palette.blue`；单面板宽度按 `#grid(columns: (12cm,))` 或直接不设栅格。
- **图注**（写进 Typst 组件 slot，行尾反斜杠换行）：

```
**一条路径，与它周围的岔路**\
实线是被写进论文的那条路。虚线是同一段工作里真实发生过的其余部分：试过又放下、绕远又回来、以及从未发表的负结果。\
读者能看见终点，看不见来路。
```

### 7.2 提案 B（Typst）：来源可见性对照双面板 → §6

- **画什么**：左右两个 8cm 面板（`#grid(columns: (8cm, 8cm), gutter: 1cm, …)` 照 eve 的 `marginal.typ`）。左面板"人与人"：上方一个节点（"论文 B"），下方三个节点（"论文 A1/A2/A3"），三条**带箭头的实线**指向它，另加一个小节点"数据 / 图像"；右下角一行注"引用网络：每次使用都留痕"。右面板"人与 AI"：上方一个节点（"AI 产出的成果"），下方三个节点画成**空心方格**（没有可指的对象），箭头改为虚线并停在半空；右下角一行注"来源：不可追溯"。
- **论证功能**：把 §6 的核心问题结构化——同一条"成果—来源"关系，在人与人之间是可追溯的实线，在人与 AI 之间是断开的虚线。它替掉一段解释性文字，并让后文"这层信任从未被建立"有出处。
- **实现**：`ripple.typ`（同目录）；`content(...)` 放文字节点（内容 ≤6 字 / 行），`line(..., mark: (end: ">"))` 画实线箭头，虚线箭头用 `mark: (end: ">"), stroke: (dash: (2pt, 4pt))`。
- **图注**：

```
**可追溯与不可追溯**\
（左）人与人：成果之间的引用关系留下可核对的痕迹。\
```
